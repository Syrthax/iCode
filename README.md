# iCode

A native macOS code editor, built in Swift and SwiftUI.

iCode is a fork of [CodeEdit](https://github.com/CodeEditApp/CodeEdit) and continues development independently.

## Building

Requirements: macOS and a recent version of Xcode.

1. Clone the repo: `git clone https://github.com/Syrthax/iCode.git`
2. Open `CodeEdit.xcodeproj` in Xcode.
3. Select the `CodeEdit` scheme (it builds **iCode.app**) and press Run.
